# عدّاد غازات العائلة 💨👑

تطبيق مضحك لعائلة من أربعة أفراد: يعدّ الغازات اليومية مع درجة كراهة الرائحة، ونقاط إضافية، وتصويت العائلة، وإحصائيات وشارات، وتتويج «☢️ ملك النووي» كل شهر.

- `index.html`: التطبيق القابل للتثبيت على الهاتف (يعمل بدون إنترنت، والبيانات على الجهاز).
- `app.html`: مصدر النسخة المشتركة على Claude، و`build.sh` يبني منه `index.html`.
- `sw.js` و`manifest.json` والأيقونات: للتثبيت كتطبيق.
